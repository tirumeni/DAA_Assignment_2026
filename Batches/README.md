# 📡 Sensor Telemetry Compression using Huffman Coding

## 📖 Project Overview

This project implements **Sensor Telemetry Compression using Huffman Coding** as part of the **Design and Analysis of Algorithms (DAA)** course.

The system compresses sensor telemetry data using the **Huffman Coding algorithm**, reducing storage requirements and transmission bandwidth while preserving the original information. The compressed data can be decoded back to its original form without any loss.

## ⚙️ Algorithm Used

### Huffman Coding

Huffman Coding is a **lossless data compression algorithm** that assigns shorter binary codes to frequently occurring characters and longer binary codes to less frequent characters.

### Steps

1. Read the input sensor data.
2. Calculate the frequency of each symbol.
3. Build a Huffman Tree.
4. Generate Huffman Codes.
5. Encode the data.
6. Decode the compressed data.
7. Verify the decoded output matches the original data.
